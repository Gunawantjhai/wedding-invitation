# Background Music

Add a single royalty-free instrumental track here as:

```
wedding-theme.mp3
```

Referenced from `MUSIC_TRACK_URL` in `src/constants/wedding.ts`. Keep the
file under ~3–4MB (encode at ~128kbps) so it starts playing quickly on
mobile connections. Good royalty-free sources: Pixabay Music, YouTube Audio
Library, or a licensed track from Epidemic Sound / Artlist.
